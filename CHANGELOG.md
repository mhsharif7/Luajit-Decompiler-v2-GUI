# Changelog

## 1.0.0 - 2026-08-30

First stable release.

### Added

- Windows 10/11-oriented WinForms interface
- Drag/drop and file/folder selection
- Recursive folder scanning with two-stage progress
- LuaJIT 2.0 and 2.1 bytecode detection
- Batch decompilation with per-file status and cancellation
- Output-folder selection and directory-structure preservation
- Lua preview and GUI log/error display
- Native decompiler options `-f`, `-s`, `-i`, `-m`, `-u`, and `-e`
- Open-output-folder action
- Result context menu and double-click open behavior
- Persistent output/options/window settings
- About dialog with license and upstream attribution
- Application and assembly version metadata
- Third-party license notices for the bundled LuaJIT Decompiler v2 executable

## 0.9.0

Pre-release used to validate folder scanning, bytecode detection, batch decompilation, cancellation, preview, and the revised Windows UI.
