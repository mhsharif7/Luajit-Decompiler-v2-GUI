# Changelog

## [1.1.1] - 2026-10-09

### Added
- New custom application icon for Windows.

### Changed
- Updated executable and window branding.
- Updated application version to 1.1.1.

### Compatibility
- Windows 10/11 (x64).
- Self-contained .NET 8 application.
- No changes to the LuaJIT decompilation engine.

### Added

- Added Light and Dark theme switching.
- Added Dark Mode styling across the main application interface.
- Added dark styling for the decompile progress bar.
- Added dark theme support for preview and log areas.

### Changed

- Improved button, input field, file grid, status, and context-menu styling for theme consistency.
- Improved contrast and readability in Dark Mode.
